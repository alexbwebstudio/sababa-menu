# סבבה — дневное меню с админкой

Одностраничный сайт (иврит, RTL) + встроенная админка для правки текстов и картинок.
Структура страницы фиксирована, меняется только контент. Хостинг — Netlify,
данные и картинки хранятся в **Netlify Blobs** (отдельная база не нужна).

## Структура

```
public/                 статика: index.html, styles.css, app.js, sw.js, манифест, иконки
netlify/functions/
  content.mjs           GET /api/content — контент; PUT — сохранить (нужен вход)
  login.mjs             POST /api/login — проверка пароля, выдаёт токен на 12 ч
  upload.mjs            POST /api/upload — загрузка картинки (нужен вход)
  image.mjs             GET /api/image/:id — отдача картинки
netlify/lib/auth.mjs    пароль и подписанные токены
netlify.toml            настройки сборки
```

## Деплой (≈5 минут)

1. Залейте папку в репозиторий GitHub (или GitLab/Bitbucket).
2. Netlify → **Add new site → Import an existing project** → выберите репозиторий.
   Build command оставьте пустым, publish directory подтянется из `netlify.toml` (`public`).
3. **Site configuration → Environment variables** → добавьте
   `ADMIN_PASSWORD` = ваш пароль (длинный, 12+ символов).
4. **Deploys → Trigger deploy**, чтобы переменная применилась.

Альтернатива без Git: `npm i -g netlify-cli`, затем в папке проекта
`netlify login`, `netlify init`, `netlify env:set ADMIN_PASSWORD "…"`, `netlify deploy --prod`.
(Перетаскивание папки в Netlify Drop не подойдёт — функции так не собираются.)

## Как пользоваться

1. Откройте сайт → кнопка **⚙ ניהול** → введите пароль.
2. Справа/поверх открывается панель: детали дня (название, тег, день, дата, подпись,
   примечание, главная картинка) и блюда по категориям (название, цена, описание,
   значки ⓥ / 🌶 / GF, фото). Изменения сразу видны на странице.
3. Нажмите **💾 שמור** — после этого изменения видят все посетители.

Картинки перед загрузкой сжимаются в браузере до 1600 px (JPEG), лимит — 4 МБ.
Загруженные, но больше не используемые картинки удаляются автоматически через сутки
(при очередном сохранении).

## Локальный запуск

```
npm install
npm i -g netlify-cli
ADMIN_PASSWORD=test123 netlify dev
```

## Заметки

- Смена `ADMIN_PASSWORD` в Netlify (и редеплой) разлогинивает все сессии.
- Если на странице ничего не сохранено, показывается пример меню из `public/app.js`
  (`DEFAULT_CONTENT`) — его можно поменять под себя.
- Сайт ставится на телефон как приложение (PWA) и показывает последнюю версию меню офлайн.
